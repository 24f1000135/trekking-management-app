# Trekking Management App

# Project Overview 
The Trekking Management is a web application that replaces manual spreadsheet based tracking with a role-based automated system. It can manage trek approvals, track bookings, avoid overbooking, and maintain trek history without relying on spreadsheets, phone calls or manual coordiantion.

# Frameworks Used
Backend: Flask (Python)
Frontend: HTML5, CSS3(custom styling), Bootstrap 4
Templating: Jinja2
Database: SQLite
Logic: Pure Python

# Setup and Run
1. Create virtual environment: "python -m venv venv"
2. Activate (windows): "venv\Scripts\activate"
3. Install dependencies: "pip install -r requirements.txt"
4. Run: "python app.py"
5. Open browser at: "http://127.0.0.1.5000"

The database will be created automatically on first run.
