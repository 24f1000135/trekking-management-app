# Trekking Management App

# Project Overview 
The Trekking Managemnt is a web application that replaces manual spreadsheet based tracking with a role-based automated system. It can manage trek approvals, track bookings, avoid overbooking, and maintain trek history without relying on spreadsheets, phone calls or manual coordiantion.

# Frameworks Used
Backend: Flask (Python)
Frontend: HTML5, CSS3
Templating: Jinja2
Database: SQLite
Logic: Pure Python
